{
  "id": "example",
  "name": "Example extension",
  "kind": "analysis",
  "description": "One ASCII sentence.",
  "enabled": false,
  "docs_url": "https://example.com/"
}

API 与文档

GET /api/connectors 英文 ASCII JSON：连接器、插件清单、计数、警告。 插件协议 v1 id / name / kind / description / enabled / docs_url；清单绝不执行。 CWE 漏洞分类 代码修复卡片里的 CWE 链接来自这里，便于统一复核口径。 OWASP Top 10 把代码级问题映射到常见风险类别与修复建议。

连接器状态来自本机环境、PATH 与已安装模块；它是「是否具备接入条件」，不是远端可用性承诺。 插件清单只读，不会被加载执行。
