# fixtures/public — public sample directory

Allowed:

- Samples compiled or constructed by the team;
- Public CTF, teaching, or historical CVE binaries;
- Each sample's provenance: source, build method, SHA-256.

Not allowed:

- Client-provided binaries or any confidential derived content;
- Unauthorized third-party binaries.

Sample binaries may be large; confirm with the team before committing them (Git LFS may be
required). Record provenance and hashes in `PROVENANCE.md` in this directory once Member 3
provides the template.
